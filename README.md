# AstroDiscovery downloads

Installers for **AstroDiscovery**, free astrophotography software by [Ranging](https://ranging.studio). It is in **Alpha**: in active development, so expect rough edges.

Get the latest from [Releases](../../releases/latest):

- **Mac** (Apple silicon): open the `.dmg` and drag AstroDiscovery to Applications.
- **Windows 10/11**: run the `Setup.exe`.
- **Raspberry Pi / Linux server**: `curl -fsSL https://github.com/GBoothby/AstroDiscovery-downloads/releases/latest/download/install.sh | bash`

Installed copies update themselves to each new release. Use is under the licence agreement shown when you install.
